# MASA

MASA EEG/SI analysis project source snapshot.

Current working version includes:

- Stratified 5-fold train/validate/test splitting by SI score
- MASA-TCN PLI-only experiment flow
- Ordinal regression head
- Low-vs-high SI auxiliary risk head
- Rank, risk classification, high-low separation, and variance diagnostics
- Prediction summary and diagnostic scripts under `tools/`

Large experiment outputs, model weights, logs, cached files, and local IDE files are excluded.
